# Project Documentation

This directory contains the maintained documentation for the implemented
Continuous Auth platform. The documents focus on the system as it exists:
its architecture, data and policy model, dashboard surface, and deployment
properties.

## Reading order

1. [system-overview.md](./system-overview.md): purpose, scope, capabilities,
   and engineering principles
2. [architecture.md](./architecture.md): runtime topology, ownership, and
   event lifecycle
3. [model-and-policy.md](./model-and-policy.md): data, scoring, privacy, and
   policy behavior
4. [dashboard.md](./dashboard.md): analyst and administration workflows
5. [reproducibility.md](./reproducibility.md): setup, validation, and
   deployment portability
